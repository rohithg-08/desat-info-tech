✦ Client Confidentiality & Data Security

Privacy Policy & Security Standards

Last Updated: October 1, 2026 • Desat Info Tech

1. Our Confidentiality Commitment

Desat Info Tech is a software development company focused on delivering innovative digital solutions. We specialize in custom software development, web applications, mobile apps, AI solutions, cloud services, UI/UX design, and digital transformation. Our mission is to help businesses grow through reliable, scalable, and modern technology.

We maintain strict confidentiality protocols. We do not share, sell, or disclose client code, business logic, customer databases, or proprietary project specifications under any circumstances. All technical engagements are backed by formal Non-Disclosure Agreements (NDAs).

2. Information Collected During Project Inquiries

When you contact Desat Info Tech or partner with our engineering squads, we collect:

  • Contact & Corporate Details: Name, business email, company name, phone number, and communication records.
  • Project Requirements: Product specifications, architecture blueprints, feature lists, and design assets shared to facilitate project estimates and development.
  • Technical Infrastructure Credentials: Environment credentials, repository access, and cloud console tokens provided strictly under secure encryption for deployment.

3. Source Code & Intellectual Property Ownership

Unless explicitly agreed otherwise in a custom software agreement, you retain 100% full intellectual property (IP) and source code ownership over all deliverables, web applications, mobile apps, database schemas, and AI configurations created by Desat Info Tech for your organization.

4. Development Environment & Cloud Security

Desat Info Tech adheres to industry security best practices (including OWASP Top 10 and SOC-2 guidelines). Development workstations, Git repositories, and staging cloud environments employ multi-factor authentication (MFA), role-based access control, and end-to-end TLS 1.3 encryption.

5. Third-Party Tools & Cloud Infrastructure

During development, we deploy client software onto verified cloud infrastructure providers (such as AWS, Google Cloud, Microsoft Azure, and Docker) chosen by and owned by the client. Client credentials and API keys are stored in encrypted secret managers and never hardcoded in source repositories.
